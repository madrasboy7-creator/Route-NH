# Route NH — GPS & Telemetry Integration Architecture

## 1. Overview

Route NH is designed to ingest telemetry data from physical AIS-140 certified GPS hardware installed on fleet vehicles (**Truck 01** and **Truck 02**), with seamless fallback to driver mobile device GPS when necessary.

For development, testing, and continuous cloud demonstration, the platform includes a **Highway Corridor Telemetry Simulator** that produces realistic GPS telemetry along active Indian National Highways (NH 48 and NH 44).

## 2. Ingestion Protocols & Hardware Specifications

### 2.1 Hardware Configuration
- **Truck 01**:
  - Device Model: AIS-140 Teltonika FMB920
  - IMEI: `867492040192831`
  - Protocol: Traccar HTTP Webhook / OsmAnd GET
  - Update Interval: 15 seconds (moving), 180 seconds (stopped)
- **Truck 02**:
  - Device Model: AIS-140 Concox GT06N
  - IMEI: `867492040192832`
  - Protocol: Traccar HTTP Webhook / GT06 TCP
  - Update Interval: 15 seconds (moving), 180 seconds (stopped)

### 2.2 Telemetry Ingestion Endpoint
- **URL**: `/api/v1/gps/telemetry`
- **Method**: `POST` (JSON) or `GET` (OsmAnd query params)
- **Payload Schema**:
  ```json
  {
    "imei": "867492040192831",
    "latitude": 13.0827,
    "longitude": 80.2707,
    "speed": 54.2,
    "heading": 275.0,
    "accuracy": 4.5,
    "altitude": 18.0,
    "battery": 98.0,
    "ignition": true,
    "timestamp": "2026-11-26T18:30:00Z"
  }
  ```

## 3. High-Fidelity Highway Corridor Simulator

To enable realistic testing of tracking UI, geofencing, and ETA calculations without requiring the physical trucks to be on the road, the Route NH Telemetry Simulator models journeys along India's major transport corridors:

1. **NH 48 (Golden Quadrilateral — South/West)**:
   - Route: Chennai -> Kanchipuram -> Vellore -> Krishnagiri -> Hosur -> Bengaluru -> Tumkur -> Hubbali -> Belagavi -> Kolhapur -> Pune -> Mumbai
   - Total Distance: ~1,340 km
   - Default Assignment: **Truck 01**

2. **NH 44 (North-South Corridor)**:
   - Route: Delhi NCR -> Faridabad -> Mathura -> Agra -> Gwalior -> Jhansi -> Nagpur -> Hyderabad -> Bengaluru
   - Total Distance: ~2,175 km
   - Default Assignment: **Truck 02**

### UI Transparency Rule
Whenever telemetry is generated by the simulator:
- The database records `isSimulated: true` and `source: "SIMULATOR"`.
- The customer and platform tracking interfaces display an informational pill: `SIMULATED TELEMETRY (DEV/TEST MODE)` so users and operators are never misled regarding the physical vehicle location.
